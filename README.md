# java-lotto-precourse

## 입력
- [x] 구입 금액 입력
- [x] 당첨 번호 입력
- [x] 보너스 번호 입력

## 출력
- [x] 발행된 로또 번호 출력
- [ ] 당첨 통계 출력, 수익률 (소수점 둘째 자리 반올림)

## 로또
- [x] 로또 1~45의 중복없는 6자리 숫자 검증
- [x] 로또 번호 오름차순 정렬 
- [x] 로또 번호 출력 포맷팅

## 로또 뭉치
- [x] 로또 여러 개 묶음 생성
- [x] 로또 뭉치 출력 포맷팅

## 로또 발행기
- [x] 구입 금액 1000원 단위 검증, 예외 처리
- [x] 로또 1개 발행: 1 ~ 45 사이의 중복 아닌 6개 번호 랜덤 생성
- [x] 로또 N개 발행: 구입 금액 / 1000 만큼 로또 발행

## 당첨 결과 계산기
- [x] 당첨 번호 6개, 보너스 번호 1개 검증, 예외 처리
- [x] 당첨 내역을 기준으로 당첨 결과 계산
  - 3개 일치: 5,000원
  - 4개 일치: 50,000원
  - 5개 일치: 1,500,000원
  - 5개 + 보너스 번호 일치: 30,000,000원
  - 6개 일치: 2,000,000,000원
- [x] 수익률 계산: (총 당첨 금액 / 총 구입 금액) * 100
